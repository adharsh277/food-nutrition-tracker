# 🍎 Food Nutrition Tracker

A cross-platform Food Nutrition Tracking application built using **Expo (React Native)**.  
The app allows users to recognize food items, track nutrition, and monitor calorie intake.  
It supports **Android, iOS (Expo Go)** and **Web deployment via Vercel**.

---

## 🚀 Features

- 📷 Food Recognition
- 🥗 Nutrition Tracking
- 🔢 Calorie Monitoring
- 📊 Simple & Clean UI
- 🌐 Web Compatible (React Native Web)
- 📱 Runs on Expo Go (Mobile)

---

## 🛠 Tech Stack

- **Expo SDK 54**
- **React Native**
- **React Navigation**
- **React Native Web**
- **Node.js**
- **Vercel (Web Deployment)**

## 🔧 Installation

Clone the repository:

git clone https://github.com/your-username/food-nutrition-tracker.git
cd food-nutrition-tracker
Install dependencies:

npm install

## Run Locally
📱 Run on Mobile (Expo Go)
npx expo start


Scan the QR code using Expo Go app.

## Run on Web
npx expo start --web

##  Production Web Build

Generate static web build:

npx expo export --platform web


This creates:

dist/
